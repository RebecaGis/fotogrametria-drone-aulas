Site para organização de aulas e recursos de fotogrametria com drone, com servidor Node.js/Express e banco PostgreSQL local.

## Estrutura

- `projeto-fotogrametria/public/`: interface HTML e recursos visuais.
- `projeto-fotogrametria/server.js`: servidor e endpoints de recursos.
- `projeto-fotogrametria/package.json`: dependências e comandos.

A configuração do banco precisa ser adaptada ao ambiente local. O repositório não inclui o esquema SQL para criação das tabelas.
